Personalization Engine — Báo cáo tiến độ

Vertical 1 học thói quen từng tài xế qua các chuyến đi, đề xuất ngưỡng an toàn cá nhân hoá cho Safety Kernel (V4) và sinh lời giải thích tiếng Việt cho Cockpit (V2) — chỉ tư vấn, không bao giờ ra lệnh xe.

01 Tóm tắt giải pháp

Guardian là hệ điều hành ADAS gồm nhiều vertical. Vertical 1 — Personalization Engine là lớp cá nhân hoá & giải thích: nó nhận telemetry an toàn từ V3 (perception) và V4 (world model), học baseline hành vi của từng tài xế, rồi cung cấp hai đầu ra:

  • Ngưỡng an toàn cá nhân hoá (advisory) cho V4 đọc — luôn kẹp trong "safety floor" do V4 sở hữu.
  • Lời giải thích tiếng Việt ngắn gọn, có căn cứ cho V2 hiển thị + đọc TTS, giữ niềm tin tài xế.

Bốn ràng buộc kiến trúc được thực thi bằng code, không chỉ tuyên bố: (1) advisory-only; (2) chỉ cá nhân hoá sau ≥3 chuyến; (3) giải thích grounded + có fallback, không bịa; (4) chạy edge, không cần phần cứng mới.

03 Kiến trúc & luồng end-to-end

[V3 Perception] [V4 World Model / Safety Kernel] risk embedding driver state · quyết định └──────────┬──────────────┘ ▼ TelemetryEvent VERTICAL 1 — PERSONALIZATION ENGINE ingestion/ → Feature Store (append-only theo chuyến) memory/ → Driver Memory + State Machine + Learning Loop reasoning/ → Phi-3 (hoặc fallback) → giải thích grounded services/ → threshold · explanation · consent api/ → REST (FastAPI) │ GetPersonalizedThreshold │ GetExplanation ▼ (số advisory) ▼ (text_vi + TTS) V4 Safety Kernel V2 Cockpit HMI

Quyết định kiến trúc: spec vẽ gRPC; bản này dùng REST/FastAPI để đồng bộ với phần còn lại của repo (V2 Cockpit cũng REST). Lớp service bên dưới transport-agnostic — dựng gRPC sau chỉ cần tái dùng nguyên service, không sửa logic.

Stack: Python 3.14 · FastAPI · Pydantic v2 · SQLite + JSONL (feature/memory store) · numpy (cosine retrieval) · ONNX Runtime GenAI cho Phi-3-mini INT4 (tùy chọn) · pytest.

04 Kết quả đã hoàn thành

Đã chạy được (end-to-end)

  • Kiến trúc phân lớp đầy đủ: models → ingestion → memory → reasoning → services → api → client
  • State machine 3 trạng thái + EMA baseline + safety-floor clamp
  • Reasoning engine với confidence gate chặn hallucinate + fallback tất định
  • 14 REST endpoint (telemetry, threshold, explanation, memory, consent…)
  • Client cross-vertical để V4/V2 gọi bằng Python sạch
